## What Is This Project?

Right now, this is just my attempt to build a scientific calculator using an ESP32, a TFT display, and a 4×4 keypad.

I am using Wokwi to test the circuit and code before trying anything with actual hardware.

The idea is to make a calculator that can perform scientific calculations and, eventually, matrix operations that I need for my engineering studies.

## Technologies Used

- ESP32 DevKit V1
- 2.8-inch ILI9341 TFT display
- 4×4 matrix keypad
- Arduino C++
- Wokwi Simulator
